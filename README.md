# DTMF-encoder-and-decoder

DTMF (Dual-Tone Multi-Frequency) is a signaling system used in telecommunications.

When a key on a telephone keypad is pressed, a unique combination of two tones is generated. 

Each key corresponds to a specific high-frequency and low-frequency tone. 

DTMF tones are used for various applications, including: 

Entering digits on telephones. 

Activating features on interactive voice response systems (IVRS). 

Remote control signaling.
